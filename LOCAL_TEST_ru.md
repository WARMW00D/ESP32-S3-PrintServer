# Локальная проверка IPP на HP LaserJet P2015 и Poco X7 Pro

Это экспериментальная версия. Сборка для esp32s3 проверена; печать на
реальной связке ESP32 + P2015 + Poco пока не проверена. В GitHub эта
версия не отправлена.

## 1. Прошить из исходников

1. Распакуйте архив целиком. Откройте `ESP32-S3-PrintServer.ino` в Arduino IDE.
   Файлы `MobilePrint.h`, `IppCodec.h`, `PwgRaster.h` должны лежать рядом.
2. Установите ядро **esp32 by Espressif Systems 3.3.10**.
3. Настройки остальных пинов/USB/PSRAM/дисплея — в основном README.
   **Partition Scheme для этой сборки: 16M Flash (3MB APP/9.9MB FATFS).**
4. Библиотеки: EspUsbHost, Adafruit_NeoPixel, Adafruit_GFX, Adafruit_SSD1306, Adafruit_BusIO.
   В архиве есть проверенные копии в `dependencies/libraries`.
   При необходимости скопируйте каждую папку библиотеки в папку
   `libraries` вашего Arduino Sketchbook (обычно `Документы/Arduino/libraries`),
   затем перезапустите Arduino IDE. Не оставляйте одновременно разные
   копии одной библиотеки. Версии и commit — в `BUILD_INFO.json`.
5. Скомпилируйте и загрузите. Serial Monitor: **115200 бод**.

## 2. Сборка прошивки

В этом архиве лежат актуальные исходники. Соберите проект Arduino IDE
с указанными ниже параметрами и загрузите полученный `.bin` на плату.
Старые бинарники намеренно не включены: они не содержат последних изменений
600 dpi, дуплекса и корректного завершения PCL/PJL-задания.

Первичная полная прошивка (замените COM5 на порт платы):

```text
python -m pip install esptool
python -m esptool --chip esp32s3 --port COM5 write-flash 0x0 firmware/full-flash.bin
```

Для первой проверки проще загрузить проект из Arduino IDE.

## 3. Подключить Poco

1. Включите P2015 и подключите его к USB Host.
2. Подключите ESP32 к домашнему Wi-Fi. Подключите Poco к той же сети.
   Также можно подключить Poco к точке доступа ESP32 — IP `192.168.4.1`.
3. В настройках телефона найдите **Печать**. Включите стандартную службу
   печати Android. Если не обнаруживает сервер, попробуйте Mopria Print Service.
   Поддержка конкретной службы будет подтверждена вашей проверкой.
4. Выберите **HP P2015 ESP32**. Если автоматическое обнаружение не сработало,
   добавьте принтер по IP. IPP-адрес: `ipp://IP_ПЛАТЫ:631/ipp/print`.
5. Откройте `tests/test-page.pdf` на телефоне и выберите «Печать».
   Настройки: **A4, книжная ориентация, чёрно-белая, один экземпляр,
   600 dpi по умолчанию. Для P2015d можно выбрать двухстороннюю печать
   по длинной или короткой стороне; начальную проверку лучше сделать односторонней.**.
6. На первых двух страницах проверьте текст, серую шкалу, рамку и порядок
   страниц. Линия должна иметь длину 100 мм при печати в реальном размере.

## 4. Если Android не печатает

Из компьютера в той же сети можно проверить сервер без службы Android:

```text
python tools/ipp_smoke.py 192.168.4.1
python tools/ipp_smoke.py 192.168.4.1 --print
python tools/ipp_smoke.py 192.168.4.1 --print --chunked
```

Первая команда только читает свойства. Каждая команда с `--print` печатает
одну страницу сетки и градиента. Укажите фактический IP платы в вашей сети.
Это помогает отличить проблему USB/PCL от несовместимости службы Android.

При проблеме сохраните Serial-лог от загрузки до ошибки, особенно строки
`[IPP]` и `[USB]`, и скриншот выбора принтера/ошибки на Poco. Сообщение
`operation=... status=...` показывает операцию и причину отказа до печати.

## Ограничения первой версии

- A4 в книжной ориентации, 600 dpi по умолчанию (300 dpi также поддерживается), один экземпляр.
- Для HP P2015d поддерживаются односторонняя печать и автоматический дуплекс по длинной/короткой стороне.
- PWG Raster `black_1`, `sgray_1`, `sgray_8`; PDF растеризует телефон.
- Один активный документ (может содержать несколько страниц), максимум
  128 МБ передаваемых данных; очередь на диске отсутствует.
- Отмена не может вернуть уже переданные/напечатанные страницы.
- «Completed» означает успешную USB-передачу, а не подтверждение выхода бумаги.
- AirPrint, Bluetooth и сертификация Mopria/IPP Everywhere отсутствуют.
- Пароль портала не защищает порт IPP. RAW/LPR остаются как раньше;
  их старые обработчики блокируют цикл во время своих заданий.

## Проверки разработчика

Сборка Arduino-ESP32 3.3.10; ASan/UBSan-проверки декодера, HTTP framing,
IPP-запросов, отмены, Create-Job/Send-Document, таймаутов и USB-ошибок.
Независимый файл из libcups: 3 страницы, black_1/sgray_1/sgray_8.
Самостоятельный запуск тестов на Linux с g++:

```text
bash tests/run.sh
python tests/cups_fixture.py /tmp/cups.pwg
bash tests/run.sh /tmp/cups.pwg
```

Спецификации: PWG 5102.4-2012, RFC 8010/8011; в памяти хранится только
заголовок/строка растра и ограниченный набор метаданных IPP, не вся страница.
