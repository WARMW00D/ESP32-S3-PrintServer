# ESP32-S3-PrintServer

Превратите обычный USB-принтер в WiFi-сетевой принтер с помощью ESP32-S3
в роли USB-хост-моста — без Raspberry Pi, без выделенного компьютера.

Родная периферия USB-OTG у ESP32-S3 работает как **USB-хост**, напрямую
общается с принтером через его интерфейс USB Printer Class и предоставляет
его в локальной сети как стандартный принтер по протоколам
**Raw/JetDirect (порт 9100)** и **LPR/LPD (порт 515)** — теми же
протоколами, что используют настоящие сетевые принтеры и принт-серверы.
Любой компьютер в сети (Windows, macOS, Linux) может добавить его как
обычный TCP/IP-принтер, установить драйвер производителя и печатать по
WiFi.

Собрано и проверено, например, на **HP LaserJet P2015**, но должно
работать с любым принтером, предоставляющим стандартный двунаправленный
интерфейс USB Printer Class (07/01).

## Возможности

- **USB-хост-мост** — родной порт USB-OTG ESP32-S3 напрямую управляет
  принтером; после прошивки компьютер или Raspberry Pi не нужны.
- **Два сетевых протокола печати** — Raw/AppSocket на порту 9100 и
  LPR/LPD на порту 515, работают одновременно.
- **Настоящая идентификация принтера** — читает реальные строковые
  дескрипторы USB (производитель/модель/серийный номер), которые
  устройство сообщает при перечислении, без угадывания по таблицам
  VID/PID.
- **Живой мониторинг статуса по PJL** — опрашивает `@PJL INFO STATUS`
  между заданиями для PJL-совместимых (HP-подобных PCL) принтеров и
  показывает на дашборде отсутствие бумаги / офлайн / ошибки.
- **Веб-дашборд** — небольшая тёмная панель управления, которую отдаёт
  сама плата: состояние принтера, подробности USB-подключения, данные
  WiFi, свободная память, а также пошаговая инструкция по настройке
  принтера для Windows и macOS с автоматической подстановкой реальной
  модели принтера и текущего IP.
- **Настройка WiFi со сканированием сетей** — страница настройки умеет
  сканировать доступные сети и показывать их списком (с уровнем сигнала
  и значком замка для защищённых), вместо того чтобы требовать ручного
  ввода SSID; ручной ввод по-прежнему доступен для скрытых сетей.
- **Поддержка WPA2-Enterprise (802.1X)** — помимо обычных сетей
  WPA2-PSK (или открытых), страница настройки умеет подключаться и к
  сетям WPA2-Enterprise по PEAP/TTLS+MSCHAPv2 (например, `eduroam` или
  корпоративный WiFi с RADIUS-сервером), запрашивая Identity/имя
  пользователя/пароль вместо обычного пароля сети.
- **Двуязычный интерфейс (RU/EN)** — одна кнопка переключает весь портал
  между русским и английским; выбор сохраняется во flash-памяти (NVS) и
  переживает перезагрузку.
- **Опциональный пароль портала** — весь веб-интерфейс (дашборд, страница
  настройки и каждый API-маршрут) можно защитить паролем через HTTP
  Basic Auth (логин `admin`), задаётся как со страницы настройки, так и
  с дашборда. Если оставить пустым — портал остаётся открытым, это
  опциональная возможность, а не обязательное требование.
- **Опциональный OLED-дисплей 0.91" по I2C** — показывает заставку при
  загрузке, а затем текущий IP-адрес платы (IP в домашней сети после
  подключения, либо `192.168.4.1` собственной точки доступа, пока
  подключения нет), с автоматическим подбором масштаба под маленький
  экран через собственную функцию измерения текста `Adafruit_GFX`.
  Полностью опционально и управляется одним `#define` — если оставить
  выключенным, ни дополнительные библиотеки, ни проводка не нужны вовсе.
- **Надёжная передача крупных заданий** — данные печати отправляются
  через асинхронную очередь записи библиотеки USB Host с щедрым,
  настраиваемым таймаутом, а не одной блокирующей записью фиксированной
  длины. Это исключает тихую порчу крупных заданий (например,
  PCL XL-заданий с картинками), когда принтер ненадолго задумывается на
  внутреннюю обработку данных — теперь сбой честно сообщается, вместо
  того чтобы повторяться так, что на шине могли задваиваться байты.
- **Обнаружение через mDNS + SSDP/UPnP** — плата анонсирует себя в сети,
  чтобы автоматически появляться там, где это поддерживается.
- **Портал настройки WiFi с настоящим резервным вариантом** — при первом
  включении (или после сброса настроек) плата поднимает собственную
  точку доступа со страницей первоначальной настройки; в исходном коде
  нет захардкоженных учётных данных. **Печать работает сразу же через
  эту точку доступа** (`192.168.4.1`), ещё до — или вообще без —
  настройки домашней сети, и продолжает работать как резервный вариант
  в любой момент, когда настроенная сеть становится недоступна.

## Оборудование

- Плата ESP32-S3 с родным портом USB-OTG (проверено на модуле N16R8:
  16 МБ flash / 8 МБ PSRAM).
- USB-кабель, соединяющий OTG-порт платы с USB-B портом принтера.
  **Важно:** у большинства плат разработки ESP32-S3 **два** разъёма
  USB-C — только один из них подключён к родной периферии USB-OTG и
  способен работать хостом; второй — это мост UART-USB для прошивки, для
  этой цели он не годится.
- **Перемычки на плате.** Многие платы ESP32-S3 поставляются с двумя
  контактными площадками на плате, которые нужно замкнуть каплей припоя,
  прежде чем режим USB Host вообще заработает:
  - перемычка **OTG** — включает родной порт USB-OTG в режим Host; без
    неё порт остаётся только в режиме устройства, и принтер никогда не
    будет обнаружен;
  - перемычка **RGB** — питание встроенного адресуемого RGB-светодиода,
    используемого здесь для наглядной индикации статуса (для самой
    печати не обязательна, но стоит замкнуть, если хочется, чтобы
    светодиод статуса работал).

  Точное расположение и подписи площадок сверяйте по шелкографии/схеме
  конкретно вашей платы — маркировка немного отличается у разных
  производителей.
- **Опционально: OLED-дисплей 0.91" по I2C** (SSD1306, 128×32), если
  хочется видеть IP-адрес прямо на экране, а не только через веб-дашборд.
  Четыре провода (VCC/GND/SDA/SCL) на любые свободные GPIO, не
  пересекающиеся с уже занятыми пинами кнопки сброса и RGB-светодиода.

## Принтеры: что точно работает, а что может быть проблемой

Любой принтер с настоящим языком описания страницы (PCL, PostScript или
похожим) и стандартным интерфейсом USB Printer Class должен работать
хорошо, поскольку задание печати — это просто заранее отрендеренный
поток байт, который передаётся как есть.

Дешёвые **"GDI" / хостовые принтеры** (например, многие принтеры Canon
на проприетарном протоколе CAPT) формируют растровые данные на самом
компьютере и часто требуют плотного, малозадержкового двунаправленного
обмена с принтером прямо во время печати. Надёжно перебросить такое
через WiFi — принципиально другая и куда более сложная задача, чем
ретрансляция готового потока PCL/PostScript, и здесь это не проверялось.
Результат может быть непредсказуем.

## Настройка Arduino IDE

Пакет плат: **esp32 by Espressif Systems**.

> **Важно — версия ядра.** В ядре Arduino-ESP32 версии **3.3.11**
> (на основе ESP-IDF 5.5.5) подтверждена регрессия, которая ломает
> родной драйвер USB Host на ESP32-S3 (`HUB: Root port reset failed`,
> устройство никогда не перечисляется — см.
> [espressif/arduino-esp32#12783](https://github.com/espressif/arduino-esp32/issues/12783)).
> Используйте версию **3.3.10** (или ту, в которой этот баг будет
> исправлен выше по течению) через Boards Manager, пока регрессия не
> устранена.

Настройки платы, использованные при разработке:

| Настройка | Значение |
|---|---|
| Board | ESP32S3 Dev Module |
| USB CDC On Boot | Disabled |
| USB Mode | USB-OTG (TinyUSB) |
| Upload Mode | UART0 / Hardware CDC |
| Flash Size | 16MB |
| Partition Scheme | 16M Flash (3MB APP / 9.9MB FATFS) |
| PSRAM | OPI PSRAM |

## Библиотеки

- [EspUsbHost](https://github.com/tanakamasayuki/EspUsbHost) — обёртка
  для Arduino поверх родного стека USB Host `usb_host.h` из ESP-IDF.
- Стандартные библиотеки ядра ESP32 Arduino: `WiFi`, `WiFiUdp`,
  `ESPmDNS`, `Preferences`, `WebServer`.
- Только если включён опциональный OLED-дисплей
  (`ENABLE_OLED_DISPLAY 1`): `Adafruit_SSD1306` и `Adafruit_GFX` (обе
  ставятся через Arduino Library Manager). При выключенном дисплее ни
  одна из них не требуется.

## Быстрый старт

1. Установите указанные выше настройки платы в Arduino IDE, включая
   версию ядра.
2. Прошейте скетч.
3. При первом включении плата поднимает точку доступа с именем
   `PrintServer-Setup` (пароль `12345678`). **Печатать можно сразу же
   через эту точку доступа** — подключите к ней компьютер и добавьте
   сетевой принтер по адресу `192.168.4.1` (Raw-порт 9100 или LPR-порт
   515), домашняя сеть WiFi для этого не требуется. Это же работает в
   любой момент, когда плата не может достучаться до настроенной сети —
   так печать всегда остаётся доступной, а не пропадает молча.
4. Чтобы плата также стала доступна в вашей обычной домашней сети,
   откройте `http://192.168.4.1`, подключившись к этой точке доступа,
   отсканируйте сети и выберите свою (либо введите SSID вручную), и
   введите её пароль (или Identity/имя пользователя/пароль для сети
   WPA2-Enterprise). На той же странице можно сразу задать и пароль
   портала — по желанию.
5. После подключения к домашней сети откройте IP-адрес платы в браузере
   для живого дашборда, либо зайдите на `http://ESP32-PrintServer.local`,
   если ваша ОС поддерживает mDNS.
6. На компьютере добавьте новый сетевой принтер по подходящему адресу
   (IP платы в домашней сети после настройки, либо `192.168.4.1`, пока
   плата работает только через собственную точку доступа) — либо через
   **Raw/AppSocket на порту 9100**, либо через **LPR на порту 515** — и
   установите обычный драйвер принтера. Пошаговая инструкция для
   Windows и macOS показана прямо на дашборде, с автоматической
   подстановкой реальной модели принтера и текущего IP платы.
